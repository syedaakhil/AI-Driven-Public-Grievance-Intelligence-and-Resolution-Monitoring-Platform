{% translate "Frequently asked questions" %}

{% translate "There is no water supply in a street. What should we do?" %}

{% blocktranslate %}Check City news & notices on the Home page for planned maintenance first. Otherwise file it under Water supply; the target time is 48 hours.{% endblocktranslate %}

{% translate "Where do potholes and broken streetlights go?" %}

{% blocktranslate %}Both go under Roads & potholes. Mention the nearest landmark so the field team can find the spot quickly.{% endblocktranslate %}

{% translate "Sewage is overflowing on a road. Is this high priority?" %}

{% blocktranslate %}Yes. Sewage overflow and open manholes are health and safety risks. The complaint form suggests High priority when the description mentions them.{% endblocktranslate %}

{% translate "Garbage has not been collected for days." %}

{% blocktranslate %}File it under Sanitation & waste; missed collection has a target time of 24 hours.{% endblocktranslate %}

{% translate "A complaint came in on WhatsApp or social media. How is it recorded?" %}

{% blocktranslate %}File it as usual and set Received through to the channel it came from. The Home dashboard then shows how many complaints arrive through each channel.{% endblocktranslate %}

{% translate "How can a citizen know the complaint is being handled?" %}

{% blocktranslate %}Share the complaint ID. Its status moves from Submitted → Assigned → In progress → Resolved, and can be checked with Track a complaint.{% endblocktranslate %}
